# AgentTX 0.3.0 — Proof Mode

Every AI change comes with proof.

This minor release adds the argv-first `agenttx proof -- <command>` workflow,
derived commit-or-rollback decisions, portable `proof.json`, a self-contained
JavaScript-free Proof Card, exact reproduction metadata, verified typed related
evidence, and an offline semantic verifier. It also includes the deterministic
bad-agent/good-agent demonstration and the least-privilege AgentTX Proof Verifier
GitHub Action.

AgentTX isolates Git-visible repository changes; it is not an OS sandbox and
cannot reverse pushes, messages, APIs, database writes, or other external side
effects. Proof integrity is unsigned and recomputable, not producer authentication.
