# Product description

## Hook

**Make AI agents undoable.**

## Short category

**Git-style transactions for AI coding agents.**

## One-liner

**AgentTX gives AI coding agents Git-style transactions: run in isolation, inspect the result, then commit or roll back.**

## Directory description

AgentTX is a local-first open-source CLI that runs coding-agent commands in isolated Git transactions. Review the diff, side effects, deterministic risk, and project checks; accept conflict-safe file changes or discard the transaction. No cloud account, telemetry, model API key, or runtime dependency is required.

## Founder framing

AgentTX is the transaction layer for autonomous agents. The V0 wedge is coding agents and Git repositories; the long-term thesis is control infrastructure for autonomous software agents.

## Category thesis

**As software agents become autonomous, execution needs transaction semantics.**
