# AgentTX launch metrics

Manual tracking only. AgentTX has no telemetry, analytics beacon, or automatic reporting.

## Priority signals

1. An external user successfully runs AgentTX.
2. An external user uses rollback on a real session.
3. A reproducible external compatibility report arrives.
4. A user repeats the workflow.
5. An external issue or contribution improves the project.
6. npm installs.
7. GitHub stars.
