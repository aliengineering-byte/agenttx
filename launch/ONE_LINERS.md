# AgentTX one-liners

## 10 words

Git-style transactions that make risky AI coding-agent sessions safely undoable.

## 20 words

Run coding agents in isolated Git transactions, inspect every change, then commit the good or roll back the entire session.

## 50 words

AgentTX wraps the coding agent you already use in an isolated Git transaction. The agent works away from your original repository; when it exits, you inspect the diff, side effects, risk, and checks. Accept the transaction or roll it back. AgentTX is open source, local-first, and not an OS sandbox.

## Founder one-sentence thesis

As agents gain autonomy, execution needs transaction semantics.
